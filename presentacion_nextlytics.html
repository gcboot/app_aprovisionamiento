Introducción

Nextlytics es una plataforma diseñada para optimizar la planeación de inventarios en empresas de venta por catálogo. Utiliza análisis predictivo y dashboards interactivos para reducir pérdidas y apoyar decisiones basadas en datos.

Contexto y Problema

  • Proyecciones manuales sin datos históricos
  • Rupturas de stock y sobreproducción
  • Pérdidas económicas en campañas de catálogo

Solución Conceptual

  • Supabase (PostgreSQL) como base de datos
  • Dash en Python para dashboards
  • ETL con Ventas_Raw a partir de CSV
  • Machine Learning para proyecciones
  • VPS Hostinger para despliegue
  • Seguridad: Supabase Auth + roles
